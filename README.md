# Studyverse — Fase 1: Experience Hub

Base original em React 18 + TypeScript + Vite 6 + Tailwind CSS 4.

## Instalação
- Node.js 20.19+ ou 22.12+
- `npm install`
- `npm run dev`

## Verificação
- `npm run typecheck`
- `npm run build`

O catálogo da Fase 1 contém conteúdo demonstrativo. Backend, autenticação e persistência ainda não fazem parte desta base.

## Vercel
- Framework: Vite
- Root Directory: `./`
- Install Command: `npm install`
- Build Command: `npm run build`
- Output Directory: `dist`

A estrutura inicial foi publicada preservando o ZIP original no repositório como cópia de segurança.
